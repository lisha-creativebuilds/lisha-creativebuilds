# Lisha — Creative Builds Portfolio

A dark, futuristic personal portfolio website for GitHub Pages.

## Files
- `index.html` — page content
- `style.css` — layout, colors, responsive design
- `script.js` — mobile navigation and current footer year

## Publish with GitHub Pages
1. Create a public repository named `lisha-creativebuilds.github.io` under your GitHub account.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your site URL should be `https://lisha-creativebuilds.github.io/`.

If your GitHub username differs, replace `lisha-creativebuilds` in the repository name and URL with your exact username.

## Personalize before sharing
Search `index.html` for:
- `lisha-creativebuilds` — replace if your username differs
- `YOUR_EMAIL@example.com` — replace with an email you want to publish, or remove that contact card
- `https://www.linkedin.com/` — replace with your own LinkedIn profile URL
- Certificate placeholder text — add only genuine certificates and verification links
- Project descriptions — update status, links, and details to reflect your real work

Do not publish passwords, API keys, private project code, or personal information you don't want public.
